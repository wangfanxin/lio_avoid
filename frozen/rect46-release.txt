5. HOW TO RE-FLY THIS EXACT VERSION
-----------------------------------
    cd /mnt/d/distill_self/lio_avoid
    ALT_MODE=lio NAV_SOURCE=lio WORLD="$PWD/worlds/pillars.yaml" \
    MISSION_PARM="$PWD/params/phase_a_mission_fast.parm" \
    EKF_PARM="$PWD/params/ekf_trust_lio_measured.parm" \
    GEOFENCE_M=6.60 TAKEOFF_COMMAND_M=0.2 VERTICAL_FIRST=1 VERTICAL_HOLD_S=3.0 \
        bash tools/run-mission.sh <TAG>

`SHAPING_M=0.30` adds the B1 approach-shaping experiment (off by default, as in this release);
`EXTRA_PARM=<file.parm>` appends ONE parameter file last in `--defaults` for a one-variable experiment
without touching a frozen file.  ONE FLIGHT AT A TIME: the launcher refuses to start while the stack is
alive.
