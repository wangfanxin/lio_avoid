WHY THIS IS VENDORED, NOT DEPENDED ON
-------------------------------------
The ego-planner-swarm line and the workspace that used to carry its packages ("planner_ws") are both
being dropped.  The PLAN box's output -- quadrotor_msgs/msg/PositionCommand on /plan/cmd -- is the FROZEN
plan/vehicle interface of the target architecture, so it has to outlive the planner that happens to
implement it today.  This directory is that pin.  Two packages of the same name cannot coexist in one
colcon workspace, so this copy and ego's must be the same package; the SHA-256 table is how "the same"
is checked instead of asserted.
