three different producers -- our TourPacer+CmdStream, a minimal third-party-style planner, and the

WHAT IS NOT CLAIMED.  No flight.  No ego binary was run: the ego adapter is exercised against a
B-spline built the way planner_manager builds one, not against ego_planner_node itself.  A real ego
sortie needs an ego-side launch file that does not exist yet (docs/PLANNERS.md section 3.2).

AND THE EVALUATOR UNDERNEATH IT IS ATTACKED, NOT DESCRIBED.  The adapter's positions come from
planner/bspline.py, so this round also built src/tools/test-bspline-mutations.py: nine single-token
defects injected into the evaluator, every one of which must make its selftest FAIL.  The FIRST
version of that selftest let THREE of the nine survive (a mis-indexed derivative knot difference, a
dropped degree factor, a wrong getTimeSum domain) -- all three invisible because the selftest had
only a UNIFORM knot vector, where a shifted knot window is the same numbers.  The second case (spans
0.4 / 0.5 / 0.4 s) and the central-difference reference were added because of that measurement.
