  vehicle" gate (`19766bc`) -- the refusal, not the far start, starved three sorties.

  `docs/metrics/phaseB-AP8-anchor-20261015.txt`.

  nothing watching the children; the stall escalation died of `NameError: name 'Bool' is not defined`

  POOL_SIZE=100 100 100` with 10468 x `AstarSearch: Unable to handle the initial or end point` and 10167 x
  `check_collision_and_rebound: ERROR! the drone is in obstacle` -- the map pool is exhausted, so the A* and
